# Crystal Ball Markets

We're an online broker based in Kingstown, St Vincent and the Grenadines. Alongside trading, we publish free market data tools for traders and developers.

## Free exchange rate and gold price API

Plain JSON, refreshed every minute, no sign-up:

| File | What it holds |
| --- | --- |
| [`rates.json`](https://crystalballmarkets.com/markets/api/v1/rates.json) | 60 currencies against the US dollar |
| [`gold.json`](https://crystalballmarkets.com/markets/api/v1/gold.json) | the gold price in local money in 69 countries |
| [`quotes.json`](https://crystalballmarkets.com/markets/api/v1/quotes.json) | forex, metals, energy, indices, shares and crypto quotes |

Docs and terms: **https://crystalballmarkets.com/markets/rates-api**
